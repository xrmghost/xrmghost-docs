# Community

Use this section when you want to interact with the XrmGhost team and other users in the public repository.

If something is broken, ask for a bug fix. If something is missing, ask for a feature. If you want to explore an idea, open a discussion.

## Choose the Right Path

| Path | Use it when | Open it here |
|---|---|---|
| [Report a Bug](/community/report-a-bug/) | You can reproduce behavior that does not match expected results | [GitHub Issues](https://github.com/xrmghost/xrmghost/issues/new/choose) |
| [Request a Feature](/community/request-a-feature/) | You want a new capability, improvement, or UX change | [GitHub Issues](https://github.com/xrmghost/xrmghost/issues/new/choose) |
| [Start a Discussion](/community/start-a-discussion/) | You want feedback, architectural input, or open-ended conversation | [GitHub Discussions](https://github.com/xrmghost/xrmghost/discussions) |

## Before You Open Anything

- Search existing issues and discussions first to avoid duplicates.
- Keep one topic per issue or discussion.
- Prefer concrete examples over generic descriptions.

## What Happens Next

Maintainers triage new items, ask follow-up questions when needed, and route each thread to the right backlog or team.
