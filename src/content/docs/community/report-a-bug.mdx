# Report a Bug

Use this path when XrmGhost behavior is wrong, inconsistent, or unexpectedly failing.

Open bugs in the public repository: [Create a bug issue](https://github.com/xrmghost/xrmghost/issues/new/choose)

## Before You Open a Bug

- Search existing issues to check whether the bug is already tracked.
- Reproduce the problem at least once from a clean starting point.
- Confirm you are using a current CLI and host version if your report is CLI-related.

## What to Include

Provide enough detail for someone else to reproduce the issue:

- Expected behavior
- Actual behavior
- Exact command(s) you ran
- Minimal scenario, plugin, or input that triggers the bug
- Environment details (OS, .NET runtime, relevant tool versions)
- Logs, error messages, and stack traces if available

## Good Bug Reports Are Reproducible

The fastest way to get help is to provide a minimal and repeatable example. If maintainers cannot reproduce the issue, they will usually ask for more detail before triage can proceed.

## What Happens Next

Maintainers will triage the issue, label it, and may ask clarifying questions. Once confirmed, the bug is scheduled according to impact and roadmap priorities.
