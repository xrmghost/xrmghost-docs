# Architecture

This section documents the content architecture of `xrmghost-docs`: where public documentation lives, how it is consumed, who owns each section, and the rules around manually authored versus auto-generated content.

## Pages in This Section

| Page | Description |
|---|---|
| [Source of Truth](./source-of-truth.mdx) | Establishes `xrmghost-docs` as the canonical public content source and explains how the user portal consumes it. |
| [Content Ownership](./content-ownership.mdx) | Maps each documentation section to its owning repository and team, and describes the update process. |
| [Generated vs Manual](./generated-vs-manual.mdx) | Distinguishes manually authored content from auto-generated reference content, and marks future insertion points for generated docs. |

## Summary

- All public documentation content is authored in this repo and consumed by `xrmghost-user-portal`.
- Each docs section has a defined owner and update process.
- Auto-generated content (CLI reference, attribute schema reference) does not exist yet; placeholder locations and rules are documented for when the pipelines are built.

See [Contributing](../contributing/index.mdx) for how to add or update content.
