# CLI

The `xrmghost` CLI is the primary tool for interacting with XrmGhost from a terminal. It provides commands for initialising projects, running workflows, managing configuration, and exporting data.

## What the CLI Does

- Bootstraps new XrmGhost projects (`init`)
- Executes run configurations against targets
- Manages local and remote configuration
- Exports results to supported output formats
