# Attribute Reference

This section provides one manual reference page for every current public attribute exposed by `XrmGhost.Attributes`.

## Source of Truth and Boundary

The current public contract in `xrmghost-attributes` is the source of truth for these pages.

These reference pages are **manual** documentation today. They summarize the public constructor and property surface with high confidence from source, and they should not be read as generated schema exports. A future generated reference can replace or supplement this section later without changing the underlying contract.

## Current Public Attributes

| Attribute | Primary use |
|---|---|
| [HandlesMessageAttribute](./handles-message-attribute.mdx) | Declare a handled Dataverse message name on a plugin class. |
| [InputParameterAttribute](./input-parameter-attribute.mdx) | Seed an input parameter with a JSON-shaped value. |
| [OutputParameterAttribute](./output-parameter-attribute.mdx) | Describe an expected output parameter value. |
| [PluginExecutionConfigAttribute](./plugin-execution-config-attribute.mdx) | Register entity, message, stage, mode, and impersonation metadata. |
| [PostImageAttribute](./post-image-attribute.mdx) | Provide a post-operation entity image payload and optional column filter. |
| [PreImageAttribute](./pre-image-attribute.mdx) | Provide a pre-operation entity image payload and optional column filter. |
| [SecureConfigurationAttribute](./secure-configuration-attribute.mdx) | Store a default secure configuration string for consumers. |
| [SharedVariableAttribute](./shared-variable-attribute.mdx) | Seed a shared variable value as JSON-shaped metadata. |
| [SolutionComponentAttribute](./solution-component-attribute.mdx) | Group registration into one or more Dataverse solutions. |
| [UnsecureConfigurationAttribute](./unsecure-configuration-attribute.mdx) | Store a default unsecure configuration string for consumers. |

## How to Read These Pages

- Use these pages for the current public names, constructor shape, and writable properties.
- Use the narrative docs in [Attributes Overview](../index.mdx) and [Getting Started](../getting-started.mdx) for package context.
- Stay conservative when you document behavior beyond the public contract: many downstream effects come from tools that consume the attributes, not from the attributes themselves.
