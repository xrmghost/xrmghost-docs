# Attributes

The XrmGhost attribute system provides a structured way to describe entities, their properties, and the rules that govern them. Attributes are defined in configuration and consumed by the runtime, the CLI, and the user portal.

## What Attributes Do

- Describe the shape and type of data attached to XrmGhost entities
- Enforce validation rules at ingestion and execution time
- Drive UI rendering in the user portal (labels, input types, visibility conditions)
- Serve as the contract between `xrmghost-attributes` and downstream consumers
